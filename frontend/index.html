🔄 Alur Kerja Sistem

Bagaimana request diproses di API Gateway

📋 Step-by-Step Proses
1️⃣
Validasi Request (JWT)
Token JWT diperiksa keasliannya menggunakan algoritma HS256. Jika kadaluarsa atau palsu, request ditolak.
2️⃣
Logging ke MongoDB Atlas
Setiap request yang masuk dicatat di database cloud MongoDB Atlas untuk keperluan audit dan monitoring.
3️⃣
Hitung Biaya Layanan (Fee 0.5%)
Gateway menghitung fee 0.5% dari jumlah transaksi sebagai biaya layanan integrasi.
4️⃣
Routing ke SmartBank
Data transaksi diteruskan ke SmartBank melalui HTTP POST untuk diproses (debit/kredit saldo).
5️⃣
Respons ke Konsumen
Hasil dari SmartBank dikembalikan ke konsumen beserta info fee dan catatan integrator.

📖 Dokumentasi API

Referensi endpoint yang tersedia di API Gateway

GET /generate_token_tester/{user_id}

Generate token JWT untuk testing. Token berlaku 30 menit.

Parameter Tipe Keterangan
user_id string ID pengguna (path parameter)
✅ Response 200
{ "token_buat_ngetes": "eyJhbGciOiJIUzI1NiIs..." }
POST /integrator/routing_api

Kirim transaksi melalui gateway. Request akan divalidasi, di-log, dihitung fee-nya, lalu diteruskan ke SmartBank.

Field Tipe Keterangan
user_id string ID pengguna
parameter.token string Token JWT untuk autentikasi
parameter.amount number Jumlah transaksi
✅ Response Sukses
{ "status": "sukses", "data": { "integrator_note": "Request divalidasi & log tersimpan di Atlas", "fee_diambil": 500.0, "respons_dari_smartbank": { ... } } }
POST /integrator/routing_universal

Forward request ke app UMKM manapun. Wajib isi target_app. Sudah include rate limiting, validasi JWT, validasi amount, dan logging otomatis.

FieldTipeKeterangan
user_idstringID pengguna
parameter.tokenstringToken JWT
parameter.target_appstringID app tujuan (smartbank/marketplace/pos/supplierhub/logistikita/umkminsight)
parameter.amountnumberJumlah transaksi (opsional)
parameter.target_endpointstringOverride endpoint tujuan (opsional)
✅ Response Sukses
{ "status": "sukses", "data": { "target_app": "marketplace", "fee_gateway": 250, "fee_persen": "0.5%", "response_time_ms": 42, "respons_dari_app": { ... } } }
GET /integrator/daftar_route

Tampilkan routing table — daftar semua app yang terdaftar di Gateway beserta URL dan endpoint default. Berguna untuk dokumentasi dan debug integrasi.

✅ Response 200
{ "status": "sukses", "data": { "total_app": 6, "daftar_app": [ { "app_id": "smartbank", "kelompok": "Kelompok 1", "base_url": "http://...", "default_endpoint": "/smartbank/pembayaran_transaksi" }, ... ] } }
