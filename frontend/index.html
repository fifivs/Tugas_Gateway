🔄 Alur Kerja Sistem

Bagaimana request diproses di API Gateway

📋 Step-by-Step Proses
1️⃣
Validasi Request (JWT)
Token JWT diperiksa keasliannya menggunakan algoritma HS256. Jika kadaluarsa atau palsu, request ditolak.
2️⃣
Logging ke MongoDB Atlas
Setiap request yang masuk dicatat di database cloud MongoDB Atlas untuk keperluan audit dan monitoring.
3️⃣
Hitung Biaya Layanan (Fee 0.5%)
Gateway menghitung fee 0.5% dari jumlah transaksi sebagai biaya layanan integrasi.
4️⃣
Routing ke SmartBank
Data transaksi diteruskan ke SmartBank melalui HTTP POST untuk diproses (debit/kredit saldo).
5️⃣
Respons ke Konsumen
Hasil dari SmartBank dikembalikan ke konsumen beserta info fee dan catatan integrator.

Parameter Tipe Keterangan

POST /integrator/routing_api

Kirim transaksi melalui gateway. Request akan divalidasi, di-log, dihitung fee-nya, lalu diteruskan ke SmartBank.

Field Tipe Keterangan
user_id string ID pengguna
parameter.token string Token JWT untuk autentikasi
parameter.amount number Jumlah transaksi
✅ Response Sukses
