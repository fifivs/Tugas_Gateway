TENTANG KAMI

Apa itu API Gateway?

Bayangkan Anda ingin mengirim uang dari toko online ke bank. API Gateway adalah "pintu gerbang" yang memastikan proses ini berjalan aman, tercatat, dan sampai ke tujuan.

Tanpa gateway, setiap aplikasi harus berkomunikasi langsung dengan bank — ini rumit dan rawan kesalahan. Dengan Gateway UMKM, semua menjadi terpusat, aman, dan otomatis.

🛡️
Penjaga Keamanan

Memverifikasi setiap request dengan token digital agar tidak ada pihak yang tidak berwenang

📝
Pencatat Aktivitas

Semua transaksi dicatat otomatis ke cloud untuk audit dan monitoring

🔀
Penghubung Aplikasi

Meneruskan transaksi dari aplikasi UMKM ke SmartBank secara otomatis

FITUR UNGGULAN

Semua yang Anda Butuhkan
dalam Satu Platform

Gateway UMKM menyediakan layanan integrasi lengkap untuk menghubungkan bisnis Anda dengan sistem perbankan.

🛡️

Keamanan Berlapis

Setiap transaksi diverifikasi menggunakan token keamanan digital (JWT HS256). Hanya pengguna terverifikasi yang bisa bertransaksi.

📊

Pencatatan Otomatis ke Cloud

Semua aktivitas transaksi dicatat otomatis di database cloud (MongoDB Atlas). Cocok untuk keperluan audit dan monitoring kapan saja.

💰

Biaya Layanan Transparan

Biaya gateway hanya 0.5% per transaksi — sangat terjangkau untuk UMKM. Tidak ada biaya tersembunyi, semua terlihat jelas.

🏦

Terhubung ke SmartBank

Transaksi Anda diteruskan secara otomatis ke SmartBank untuk diproses (debit/kredit saldo), tanpa perlu koneksi manual.

⚡

Integrasi Mudah

Tersedia endpoint API standar yang bisa langsung digunakan oleh aplikasi lain. Dokumentasi lengkap di dashboard Anda.

📱

Dashboard Interaktif

Kelola transaksi, buat token keamanan, hitung biaya layanan, dan lihat dokumentasi — semua dari satu dashboard modern.

CARA KERJA

Proses Sederhana,
Hasil Maksimal

Hanya dengan beberapa langkah, transaksi Anda diproses secara aman dan cepat.

01

Generate Token

Buat token JWT melalui dashboard. Token ini berlaku selama 30 menit untuk autentikasi transaksi Anda.

02

Kirim Transaksi

Masukkan detail transaksi beserta token JWT. Gateway akan memvalidasi dan memproses permintaan Anda.

03

Validasi & Logging

Sistem memverifikasi token, mencatat log ke MongoDB Atlas, dan menghitung biaya layanan secara otomatis.

04

Routing & Respons

Transaksi diteruskan ke SmartBank dan hasilnya dikembalikan kepada Anda secara real-time.
